## Rewrite `get_file_segments`

[crates/unused_finder/src/parse/exports_visitor_runner.rs](crates/unused_finder/src/parse/exports_visitor_runner.rs)

Current body parses with swc, runs `resolver(Mark::fresh, Mark::fresh, true)`
inside `GLOBALS.set(...)`, then calls `ast_segmenter::segment_file`.

The new body uses a **per-worker thread-local arena** so Rayon callers in
`unused_finder.rs` / `walk.rs` / `report.rs` reuse the same bumpalo backing
across files on each worker thread. The arena is reset (cheap — returns
chunks to the free list without freeing the backing allocation) at the end
of each call, so visitor outputs (`Vec<Segment>`) must be fully owned
(`CompactStr`/`PathBuf`/etc., never `Atom<'a>` or `&'a` into AST). This is
already true after phase 4.

```rust
use std::cell::RefCell;
use oxc_allocator::Allocator;

thread_local! {
    static PARSE_ARENA: RefCell<Allocator> = RefCell::new(Allocator::default());
}

pub fn get_file_segments(file_path: &Path) -> Result<Vec<Segment>, SourceFileParseError> {
    let source = std::fs::read_to_string(file_path)
        .map_err(|e| SourceFileParseError::LoadFile(file_path.to_path_buf(), e))?;
    if source.contains("// This file is auto-generated") {
        return Err(SourceFileParseError::AutogeneratedFile);
    }

    PARSE_ARENA.with(|arena_cell| {
        let arena = arena_cell.borrow();
        let ret = oxc_utils_parse::parse_file(&arena, &source, file_path);
        if !ret.errors.is_empty() {
            let msg = ret.errors.iter().map(|e| e.message.to_string()).collect::<Vec<_>>().join("\n");
            // Drop the borrow before reset.
            drop(arena);
            arena_cell.borrow_mut().reset();
            return Err(SourceFileParseError::Parser(file_path.to_path_buf(), msg));
        }
        if ret.panicked {
            drop(arena);
            arena_cell.borrow_mut().reset();
            return Err(SourceFileParseError::TypeScriptSyntax(
                file_path.to_path_buf(),
                "parser panicked".into(),
            ));
        }

        let semantic = oxc_semantic::SemanticBuilder::new().build(&ret.program).semantic;

        let stdio_logger = StdioLogger::new();
        let file_logger = WrapFileLogger::new(
            file_path.display().to_string(),
            source.clone(),
            &stdio_logger,
        );

        let segments = ast_segmenter::segment_file(&file_logger, &ret.program, &semantic);

        // All owned data is extracted; drop the borrow and reset the arena for next call.
        drop(semantic);
        drop(ret);
        drop(arena);
        arena_cell.borrow_mut().reset();

        Ok(segments)
    })
}
```
